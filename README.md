# EMERALD STORE

فروشگاه اینترنتی فارسی و راست‌چین با Next.js 16، React 19، TypeScript، Tailwind CSS 4 و فونت محلی Vazirmatn.

## اجرا

```bash
npm install
npm run dev
```

برای تنظیم آدرس سایت، فایل `.env.example` را به `.env.local` کپی کنید و مقدار `NEXT_PUBLIC_SITE_URL` را با دامنه واقعی خود جایگزین کنید. فایل `.env.local` محرمانه و در Git نادیده گرفته می‌شود.

برای بررسی نسخه تولید:

```bash
npm run build
npm run start
```

## ساختار داده‌ها و تصاویر

- دسته‌بندی درختی و محصولات نمونه در `src/data/categories.ts` و `src/data/products.ts` نگهداری می‌شوند.
- تصاویر نمونه محصولات، دسته‌بندی‌ها، بنرها و صفحات اشتراک‌گذاری در `public/images/` قرار دارند.
- نام فروشگاه در هدر، فوتر و Metadata با مقدار `EMERALD STORE` تنظیم شده است.
- `NEXT_PUBLIC_SITE_URL` مبنای Metadata، Sitemap و Robots است؛ مقدار پیش‌فرض فقط برای پیش‌نمایش است و پیش از انتشار باید با دامنه واقعی جایگزین شود.

## امکانات نسخه نمایشی

جست‌وجو و تاریخچه محلی، دسته‌بندی و زیر‌دسته‌بندی، فیلتر و مرتب‌سازی، جزئیات محصول و مشخصات متناسب با گروه کالا، انتخاب رنگ و سایز، سبد خرید، علاقه‌مندی‌ها و مقایسه در `localStorage` کار می‌کنند. فرآیند خرید و فرم‌های حساب کاربری نمایشی هستند؛ درگاه پرداخت، احراز هویت، API و ذخیره‌سازی سروری وجود ندارد.

## مسیرهای فروشگاه

صفحه اصلی، فهرست دسته‌بندی‌ها، دسته‌بندی و جست‌وجو، جزئیات محصول، تخفیف‌ها، پرفروش‌ها، تازه‌ها، سبد خرید، تسویه نمایشی، علاقه‌مندی‌ها، مقایسه، پروفایل و صفحات راهنمای خرید در App Router پیاده‌سازی شده‌اند.
